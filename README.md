# 🍕 Domino's Pizza Sales Analysis

## 📌 Project Overview
This project analyzes Domino's pizza sales data using Microsoft Excel to identify sales trends, customer ordering patterns, popular pizza categories, and business performance.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Data Analysis
- Data Visualization
- Excel Dashboard

## 📊 Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Total Revenue | 10,786,832 |
| Total Orders | 24,565 |
| Total Pizzas Sold | 62,087 |
| Average Order Value | 444.73 |

## 🔍 Key Business Insights

1. Chicken category generated the highest revenue of 2,825,984.
2. The Barbecue Chicken Pizza was the best-selling pizza with 3,034 units sold.
3. Large pizzas contributed the highest revenue among pizza sizes.
4. The West region generated the highest revenue of 3,641,112.50.
5. May recorded the highest monthly revenue of 1,848,120.50.
6. Bengaluru was the highest-revenue city with 942,913.

## 📁 Project Files

- `Dominos_data_xlsx.xlsx` – Excel workbook containing the dashboard, pivot tables, and sales dataset.

## 🎯 Project Objective

To transform raw sales data into meaningful business insights and support data-driven decision-making through Excel dashboards and analysis.
